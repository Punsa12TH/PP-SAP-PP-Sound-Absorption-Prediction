# ประวัติการทำงานของ Codex

โฟลเดอร์นี้เก็บสรุปแชทเป็น Markdown สำหรับส่งต่องานใน repo นี้ การบันทึกเกิดขึ้นเมื่อ Codex เขียนไฟล์สรุปตาม [AGENTS.md](../AGENTS.md)

## วิธีบันทึก

- ใช้ชื่อไฟล์ `YYYY-MM-DD-หัวข้องาน.md` และเพิ่มเลขท้ายเมื่อชื่อซ้ำ
- ใส่เป้าหมาย สิ่งที่ทำและไฟล์ที่เกี่ยวข้อง ผลการตรวจสอบ และงานที่ค้าง
- เก็บเฉพาะข้อมูลที่จำเป็นต่อการทำงานต่อ ละเว้นคีย์ รหัสผ่าน และข้อมูลส่วนตัว
- เพิ่มลิงก์ของบันทึกใหม่ไว้ด้านบนของรายการด้านล่าง
